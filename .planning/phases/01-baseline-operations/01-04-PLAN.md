<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted HTTP request -> Go handler/middleware | Headers, body, query, cookies, and route values enter the public process. |
| Go process -> logs/traces/error responses | Emitted data may be retained or exposed to operators/users. |
| future session fields -> browser session encoder | Only an opaque handle key may cross; the encoder itself belongs to a later phase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04-01 | Information Disclosure | request logging and trace fields | high | mitigate | Deny-by-default sink allow lists, path-only request events, `ReplaceAttr`, and process-level sentinel tests. |
| T-01-04-02 | Information Disclosure | startup and HTTP errors | high | mitigate | Key-only config diagnostics, generic public errors, safe correlation IDs, and no error wrapping of untrusted values. |
| T-01-04-03 | Tampering | arbitrary structured attributes | medium | mitigate | `SafeFields` drops every key not explicitly admitted for the selected sink. |
| T-01-04-04 | Repudiation | redacted operational events | low | accept | Correlation IDs and constant event names preserve operational linkage; user identity and payload detail are intentionally excluded. |
| T-01-SC | Tampering | Go logging implementation | high | mitigate | Use only Go standard library `slog`; add no package and keep the exact Go toolchain contract from Plan 02. |
</threat_model>
