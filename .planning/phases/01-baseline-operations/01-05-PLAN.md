<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request -> legacy Rust routes | Current browser/API requests may carry credentials, key bytes, search terms, and protected-field identifiers. |
| Rust route/cache/session -> logs and errors | Internal errors and request-derived values can escape into retained outputs. |
| Rust session middleware -> browser cookie | Serialized state crosses into a client-held encrypted cookie and must not contain request secrets or decoded data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05-01 | Information Disclosure | Actix request logger | high | mitigate | Replace default request-line logging with path-only constant-schema events and hostile-request capture tests. |
| T-01-05-02 | Information Disclosure | auth/unlock/route errors | high | mitigate | Remove formatted request/error values, return generic correlated responses, and inject category-specific sentinels. |
| T-01-05-03 | Information Disclosure | session cookie and cache events | high | mitigate | Assert sentinels absent from cookie/output and emit constant cache lifecycle events only. |
| T-01-05-04 | Repudiation | reduced diagnostic detail | low | accept | Correlation IDs, safe event identity, status, and duration preserve operational accountability without user/vault detail. |
| T-01-SC | Tampering | Rust dependency graph | high | mitigate | Add no crate, run every test with `--locked`, and preserve Cargo.lock. Any dependency change requires package-legitimacy review. |
</threat_model>
