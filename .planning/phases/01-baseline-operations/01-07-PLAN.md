<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted HTTP target -> Actix router | Arbitrary path and path-segment bytes enter the Rust process before resource matching. |
| Actix routing metadata -> Rust telemetry | Only code-defined resource patterns or one fixed fallback may cross into retained outputs. |
| spawned Rust process -> test captures | Empty or unreachable sinks can create false redaction confidence unless asserted before absence checks. |
